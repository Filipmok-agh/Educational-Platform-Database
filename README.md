    
# Educational Platform Database Project

This project was created by **Filip Mokrzycki**, **Piotr Kacprzak**, and **Mateusz Wójcik** as part of the development of a robust database for an educational platform, implemented using **Microsoft SQL Server**. The goal of the project was to design a scalable and efficient database system that supports various educational functions and data management needs.

## Key Features:

- **Requirements**: The full system requirements can be found in the [Wymagania](Wymagania.pdf) file, providing a comprehensive overview of the necessary features and functionalities.
- **Documentation**: All project documentation has been compiled in the [Dokumentacja](Dokumentacja.md) file. This document includes detailed explanations of the database design, the architecture of the system, and other relevant technical information.
- **Schema**: The complete database schema is available in the [Schemat](/Projektowanie/schemat.svg) file, offering a visual representation of the database structure, tables, and relationships.
- **Data Generator**: The data for the platform was generated using **Faker**, a Python library that creates highly realistic and meaningful test data. The data generation process is thoroughly documented in the [data_generate](/generowanie%20danych/data_generate.ipynb) file, which provides an easy-to-follow guide on how the data was generated and how it can be customized for different use cases.
- **[Functions](/implementacja/funkcje.md), [Triggers](/implementacja/triggery.md), [Views](/implementacja/widoki.md), [Procedures](/implementacja/procedury.md), and [Tables](/implementacja/tabele)**: Every function, trigger, view, procedure, and table within the database is described in its own separate file. This allows for easy navigation and understanding of the specific database components. In addition, a full description of all these elements is included in the comprehensive documentation.

## Technologies Used:
- **Microsoft SQL Server**: The database was developed using Microsoft SQL Server, taking advantage of its powerful features for managing relational data.
- **Python (Faker)**: The data generation was done using the **Faker** library in Python to produce realistic, synthetic test data for the platform. The process is documented in the [data_generate](/generowanie%20danych/data_generate.ipynb) file.
- **Python (Jupyter Notebook)**: The data generation is facilitated by Jupyter Notebook, offering a simple and interactive environment to create the fake data.

This project showcases our ability to design complex database systems, implement efficient data structures, and generate high-quality test data for real-world applications. It serves as a testament to our skills in database management, SQL development, data generation with **Faker**, and the creation of practical educational solutions, making it an excellent addition to our CVs.
